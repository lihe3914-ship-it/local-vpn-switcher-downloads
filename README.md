# 本地 VPN 出口切换器 · 公开下载

在 FlClash、Cloudflare WARP 和其他本机代理之间切换，支持连接检测、系统代理接管和原网络恢复。免费供个人使用，VPN 客户端、账号和订阅请自行准备。

## 下载与安装

[打开最新版本下载页（无需登录 GitHub）](https://github.com/lihe3914-ship-it/local-vpn-switcher-downloads/releases/latest)

| 电脑 | 选择文件 | 解压后运行 |
| --- | --- | --- |
| Windows 10/11 · Intel / AMD 64 位 | windows-x64.zip | Install.cmd |
| Mac · Apple M 系列 · macOS 13.5+ | macos-arm64.zip | Install.command |
| Mac · Intel · macOS 13.5+ | macos-x64.zip | Install.command |

下载文件名会带有当前版本号。完整解压后运行安装文件，会自动复制程序并创建桌面“VPN 出口切换器”和“VPN 恢复网络并退出”入口，无需安装 Node.js。

Windows 安装到 `%LOCALAPPDATA%\LocalVpnSwitcher`；Mac 安装到 `~/Applications/Local VPN Switcher`。安装不需要管理员权限，也不设置开机自启。Mac 修改系统代理时会请求授权。本程序尚未进行 Windows 发行者签名或 Apple 公证。

## 使用、更新和卸载

1. 启动桌面入口，配置自己客户端的路径、端口及控制接口。在原客户端完成登录、导入订阅和首次连接。
2. “连接当前代理”先验证出口；需要统一管理时再接管系统代理。启动本工具不会自动改变系统代理。
3. 结束时使用“VPN 恢复网络并退出”。只关闭网页不会停止后台服务。
4. 页面“检查更新”仅读取本公开仓库的版本和 SHA-256，不使用私库凭证或上传本地配置。下载新版后先在旧版恢复并退出，再运行新版安装文件。
5. 卸载使用安装目录的 Uninstall.cmd / Uninstall.command。升级与卸载保留 data/ 个人配置。Start/Stop 文件也可免安装使用。
